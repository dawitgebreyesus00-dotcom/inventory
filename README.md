# Inventory Management System

A web application for managing products, stock, suppliers, purchase orders, and sales orders.

## Features

- View and manage products and categories
- Track stock levels and adjustments
- Manage suppliers and purchase orders
- Manage sales orders
- Support user authentication and role-based actions
- View inventory reports

## Project structure

- `frontend/` — React user interface
- `server/` — application server and API
- `CONSTRAINTS_DOCUMENTATION.md` — project constraints documentation

## Getting started

Install dependencies for the frontend:

```bash
cd frontend
npm install
```

Install dependencies for the server:

```bash
cd ../server
npm install
```

Check each folder’s `package.json` for the available commands to run the frontend and server.

## Configuration

The server uses environment settings. Create a local `server/.env` file if the application requires one. Keep passwords, API keys, and other secrets out of GitHub.
